# SIRINAPHA: Baan-Pla Link

A production-quality web dashboard for monitoring mangrove forest health and forecasting artisanal fishery suitability indexes for Thailand's coastal communities.

## Features

- Real-time mangrove health monitoring using satellite NDVI data
- Fishery Suitability Index (FSI) predictions
- Degradation alert management system
- Restoration site planning and carbon credit tracking
- Comprehensive ESG reporting
- Interactive geospatial visualizations

## Tech Stack

- React 18 with TypeScript
- Vite
- TailwindCSS
- Leaflet.js for maps
- Recharts for data visualization
- React Router v6

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Deployment

### Deploy to Vercel

1. Install Vercel CLI (optional):
```bash
npm i -g vercel
```

2. Deploy:
```bash
vercel
```

Or connect your GitHub repository to Vercel for automatic deployments.

### Environment Variables

No environment variables required for the demo version with mock data.

## Project Structure

- `/src/components` - Reusable UI components
- `/src/pages` - Page components
- `/src/data` - Mock data for demonstration
- `/src/types` - TypeScript type definitions
- `/src/utils` - Utility functions

## Pilot Area

The dashboard uses realistic mock data based on the Kung Krabaen Bay pilot area in Chanthaburi province, Thailand (12.57°N, 101.90°E).
